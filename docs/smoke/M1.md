# M1 smoke checklist: Tonnetz explorer

Run `npm run dev`, open the app, and press `` ` `` to show the frame-time overlay. Budget: frame ≤ 8 ms.

## Done-when

- [ ] Click C major, then type `PLPLPL` quickly. Each press sounds and redraws on the next frame. The overlay stays green (frame ≤ 8 ms, ~60 fps).
- [ ] Keep going (`PLPLPL` ×3). The triangle walks straight down the major-thirds axis, auto-pan follows, and names drift (F♭, D♭♭, … with `= C`-style hints in the readout).
- [ ] Click nodes to build sets. Each draws the right shape:
  - [ ] C E G B → rhombus (5 thick edges)
  - [ ] C E G B♭ → triangle with a tail to B♭
  - [ ] F C G (sus4), C G D A → capsule along the fifths axis
  - [ ] A♭ C E (augmented) → capsule along the major-thirds axis
  - [ ] C E♭ F♯ A (dim7) → capsule along the minor-thirds axis
  - [ ] Removing a node from a triangle and adding it back makes it a triad again (P/L/R work)
- [ ] Hold a chord on the MIDI keyboard. It lights within a frame (green), with a ring on the lowest note. Release, and the current chord comes back. Successive chords land near each other.

## Interaction

- [ ] Hover a triangle: its P, L and R images show dashed, lettered.
- [ ] `S`, `H`, `N` from C give C♯m (D♭m by position), A♭m, Fm.
- [ ] Custom keys: `Q=PRL` works; `P=LL` and `X=PZ` show errors.
- [ ] Drag pans, the wheel zooms around the cursor, and labels sharpen shortly after the wheel stops.
- [ ] Torus: the 4×3 domain with plain spellings. Shapes crossing an edge wrap, and edge nodes light on both sides.
- [ ] Numbers: labels switch to 0–11.
- [ ] Esc clears. Reload keeps camera and toggles, not the current chord.
- [ ] First click after load sounds (audio unlocks on the first gesture). Clicks sound immediately after that.
- [ ] MIDI input picker lists the controller; unplugging and replugging it recovers.

## Performance

- [ ] During a long, fast drag the overlay's frame max stays ≤ 8 ms. "lattice tiles" shows a few ms at most while panning.
- [ ] With a chord held and the view auto-panning, frames stay green.
