# M2 smoke checklist: sketch, chart and playback

Run `npm run dev`, open the app in Firefox, and press `` ` `` for the frame-time overlay. Budget: all views together ≤ 8 ms per frame.

## Done-when

- [ ] Press `C` and paste [m2-sample-chart.txt](m2-sample-chart.txt) over the text. The status line reads "32 bars · 58 chords" and the timeline fills.
- [ ] Space plays. Bars 1–32 loop (with no loop region set, the whole sketch loops). The playhead runs, the timeline pages along, the playing block brightens, and the piano strip follows.
- [ ] The trail draws while playing: faint shapes for the last 8 chords, joined centroid to centroid with arrowheads. Amber marks a single P/L/R flip, blue a 2–3 op compound, and dashed grey a jump. With Follow on, the camera keeps the playing chord in view.
- [ ] The trail drifts and never re-centers. Each I–vi–ii–V cycle winds one lap sideways, and the chromatic Fmaj7 Fm7 Em7 slips into flat spellings. Drifted names show their `=` hint.
- [ ] Every edit undoes, each one step: add, delete, chart typing (a burst is one step), tempo, meter, loop drag, sound, voicing mode, rename. Ctrl+Shift+Z redoes. Undo never moves the camera.
- [ ] Reload: the same sketch comes back (chords, tempo, loop, name, camera), and the trail sits where it was.

## Chart drawer

- [ ] Type a bad token (`| C Xq |`). It gets a wavy underline, the error list names it, and playback keeps the last valid chords.
- [ ] Fix it: the chords update on the next keystroke.
- [ ] `.` holds, `_` rests, `%` repeats a bar, `C/E` puts E in the bass (green ring and lowest piano key), `[0 4 7 11]` and `{C E G B}` work, and `>P >L` transform the previous triad.
- [ ] `@tempo 132` changes the tempo box; changing the tempo box rewrites only the `@tempo` line.
- [ ] Add a chord from the Tonnetz while the drawer is open. The text is rewritten in canonical form, and the `#` comment lines at the top survive.

## Building on the Tonnetz

- [ ] Click a triangle and press Enter. One bar is added at the insert point (the amber caret), and the caret moves past it.
- [ ] Shift+P / Shift+L / Shift+R transform and append in one go. `PLPLPL` with Shift builds a hexatonic strip.
- [ ] Shift-click a triangle to append it. Shift-click a node to append the current draft set.
- [ ] ← / → move the caret by one chord. Appending in the middle pushes later chords back.
- [ ] Click a timeline block: it sounds its voicing, becomes current (lit, with a bass ring and its name in the readout), and the caret goes after it. P/L/R then continue from it.
- [ ] Backspace deletes the selected chord and closes the gap.
- [ ] Click empty timeline space to move the caret to the nearest boundary.

## Transport

- [ ] Drag in the timeline ruler to set a loop (snaps to bars; hold Shift for beats). The top bar shows "Loop a–b". Playing loops just that region, and a chord already sounding at the loop start re-strikes there. Click the ruler to clear the loop.
- [ ] Change the loop while playing: if the playhead falls outside, it jumps to the new start.
- [ ] Click (metronome) ticks on beats with an accented downbeat. Count-in gives one bar of clicks before playback starts.
- [ ] Sounds: E-piano, Pad and Pluck switch live. Auditions (Tonnetz clicks) never cut playback off.
- [ ] Voicing modes smooth / close / drop2 / spread change the piano strip and the sound. In smooth, a repeated chord's keys don't move.
- [ ] Edit while playing (chart, tempo, delete). Playback carries on with the change.

## Sketches

- [ ] "+ New" starts an empty sketch. It appears in the list once it has a chord or a name.
- [ ] Switch between two sketches: each reopens with its own camera and trail.
- [ ] × deletes (after a confirm).

## Performance

- [ ] While playing the sample chart at 112 bpm with Follow on, the overlay frame max stays ≤ 8 ms. The timeline costs well under 1 ms per frame.
- [ ] Typing in a 64-bar chart stays instant (re-parse ≤ 5 ms is unit-tested; the overlay shouldn't spike).
